### Deploy to GitHub Pages
1. Install dependencies safely:
```
npm install --ignore-scripts
```
2. Build + publish to `gh-pages` branch:
```
npm run deploy
```

Then enable GitHub Pages in repository settings using branch `gh-pages`.
